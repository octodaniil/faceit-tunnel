# Faceit Tunnel

Через VPN идёт только Faceit: приложение, античит и сайт.
CS2, Steam, игровые серверы и все остальные сайты идут напрямую, поэтому пинг в игре обычный.

Внутри работает [sing-box](https://github.com/SagerNet/sing-box) в режиме TUN, тот же движок, что у VPN-клиентов.
Нужна подписка VLESS (TCP, WS или gRPC), например такая же, как для Happ.

## Приложение для Windows

**[Скачать установщик](https://github.com/octodaniil/faceit-tunnel/releases/latest/download/FaceitTunnel-win-Setup.exe)** —
окно с кнопкой подключения, несколько подписок, проверка Faceit, журнал, значок в трее и автообновление.

- Windows может показать «Windows защитила ваш компьютер»: нажмите «Подробнее» → «Выполнить в любом случае».
- При запуске приложение попросит права администратора — без них туннель не создать.
- Подписки и ключи добавляются на вкладке «Настройки».

Ниже — вариант без установки, на скриптах (`.bat`).

## Скрипты

Есть два режима:

| Запуск | Как идёт Faceit | Какую страну видит Faceit |
|---|---|---|
| `start.bat` | через VPN-сервер из подписки | страну VPN-сервера |
| `start-direct.bat` | напрямую, блокировку обходит фрагментация TLS (как zapret), подписка не нужна | вашу настоящую |

Начните с `start-direct.bat`: если он открывает Faceit, Faceit видит ваш настоящий IP, и в пати
с игроками из вашей страны доступны её серверы. Если не открывает, используйте `start.bat`.

### Скачать скрипты

**[Скачать ZIP](../../archive/refs/heads/main.zip)** и распаковать в любую папку, лучше без русских букв в пути.

## Перед первым запуском

1. Отключите Happ и любые другие VPN или прокси, Proxifier тоже.
2. Если стоит zapret, добавьте IP своего VPN-сервера в `lists\ipset-exclude.txt` и перезапустите zapret.
   Скрипт сам покажет этот IP при подключении.

## Запуск

1. Запустите `start.bat` и согласитесь на права администратора.
   При первом запуске скрипт сам скачает sing-box с GitHub.
2. Вставьте ссылку на подписку (`https://...`) или на сервер (`vless://...`) и нажмите Enter.
   Вставка в чёрном окне делается правой кнопкой мыши.
3. Если серверов несколько, введите номер. Берите ближайший к себе (Европа), а не США:
   так приложение Faceit будет грузиться быстрее.
4. Не закрывайте окно, пока играете. В нём зелёным видно соединения, которые идут через VPN.

В режиме без VPN (`start-direct.bat`) подписку вводить не нужно, всё остальное так же.

Отключиться: `Ctrl+C` или закрыть окно.
Сменить подписку или сервер: `change-subscription.bat`.

## Проверка

Не закрывая окно туннеля, выполните в другом окне PowerShell:

```powershell
curl.exe -s -m 10 https://www.faceit.com/cdn-cgi/trace | Select-String '^(ip|loc)='
curl.exe -s -o NUL -m 10 -w "HTTP=%{http_code} exit=" https://www.faceit.com/; $LASTEXITCODE
```

- `loc=` — страна, которую видит Faceit: страна VPN-сервера в `start.bat`, ваша в `start-direct.bat`.
- `HTTP=403` или `200` — сайт доступен (403 — это проверка Cloudflare для curl, браузер её пройдёт).
  `exit=28` — блокировка не обойдена.

## Что идёт через туннель

| Правило | Значения |
|---|---|
| Домены (с поддоменами) | `faceit.com`, `faceit-cdn.net`, `faceit.gg`, `challenges.cloudflare.com` |
| IP-адреса | `193.41.200.0/24` |
| Процессы | `FACEIT.exe`, `faceitclient.exe`, `faceitservice.exe` |

Всё остальное идёт напрямую. Списки задаются в начале `faceit-tunnel.ps1`.

## Свой VPN-сервер дома

Если у знакомого Faceit открывается без VPN, его домашний Linux (Debian/Ubuntu) может стать
сервером: Faceit будет видеть IP и страну этого дома. Нужен белый IP (внешний адрес, на который
можно подключиться из интернета) и проброс TCP-порта 443 на роутере.

```bash
curl -fsSL https://raw.githubusercontent.com/octodaniil/faceit-tunnel/main/server/install-server.sh -o install-server.sh
sudo bash install-server.sh
```

Скрипт ставит sing-box с VLESS + REALITY, закрывает доступ к домашней сети через VPN
и печатает ссылку `vless://...` — её вставляют в `change-subscription.bat`.

## Если что-то не работает

- Закройте окно туннеля и запустите `diagnose.bat` (права администратора не нужны).
  Он по очереди проверяет, открывается ли Faceit напрямую, с разными вариантами фрагментации
  и через VPN, и сохраняет итог в `diag-report.txt`. Ключей и ссылки на подписку в отчёте нет.
- Полный лог лежит в `sing-box.log` рядом со скриптом.
- Если не открывается какая-то часть Faceit, найдите в логе домен, к которому она обращается,
  и допишите его в `$ProxyDomains` в начале `faceit-tunnel.ps1`.
- Ссылка на подписку хранится в `subscription.txt`, а ключ доступа ещё и в `config.json`.
  Никому не передавайте эти файлы.
